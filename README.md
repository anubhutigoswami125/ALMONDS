# ALMONDS

A collection of two separate browser-based projects:

## 1. ALMONDS! Nut Encyclopedia
A pop-art educational guide to edible nuts and seeds, with searchable entries and nutrition/food-science information.

- Source: [nut-encyclopedia](./nut-encyclopedia)
- Main page: [index.html](./nut-encyclopedia/index.html)
- Site information: [legal.html](./nut-encyclopedia/legal.html)

## 2. Almond
A small browser-based character-chat experiment.

- Source: [almond](./almond)

## Technology
Both projects are built as static HTML/CSS/JavaScript pages. User-created state, where applicable, is stored in the local browser rather than a shared backend.
