# ALMONDS

**ALMONDS** is the home repository for two related projects:

1. **Nut Encyclopedia** — the main project: a curated, educational reference to nuts, their nutrition, botanical background, culinary uses, and allergen considerations. *(Development space; the encyclopedia itself is not implemented yet.)*
2. **Almond** — a smaller, browser-based character-chat and storytelling app.

## Projects

### Nut Encyclopedia
Planned as the primary project in `nut-encyclopedia/`. Its content should distinguish evidence-based nutrition information from general-interest facts and clearly flag allergy considerations.

### Almond: character chat
- **Live demo:** https://anubhutigoswami125.github.io/almond/
- **Source in this repository:** [`almond/`](./almond/)

The app currently runs in the browser and stores user data locally in that browser. It does not yet have a shared account system or shared public backend.
