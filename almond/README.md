# Almond

A browser-based character-chat and storytelling app, maintained here as a smaller project alongside the planned Nut Encyclopedia.

- **Live demo:** https://anubhutigoswami125.github.io/almond/
- **Entry point:** [index.html](./index.html)

## Current behavior
The app includes character discovery, a personal character library, chat workspaces, profile settings, and browser-local data management. It currently runs without a shared backend, so local data is tied to the browser/device.

## Run locally
Open `index.html` in a modern browser. Some browser features may behave differently when opened directly from disk; using a simple local static server is preferable for development.
